Semantic Retrieval from PDFs Clear Project Explanation

This system extracts content from PDFs, converts the text into embeddings, and stores them in a FAISS index. When a user submits a query, it is embedded and compared against stored vectors to retrieve the most relevant document sections. The results are displayed through a Streamlit interface along with visual insights generated using Plotly.

End-to-End Retrieval Pipeline

  • Parsed PDF files using pdfplumber and pypdf to collect clean text sections.
  • Split documents into chunks suitable for semantic embedding and retrieval.
  • Generated dense embeddings with sentence-transformers for meaningful vector search.

Similarity Search with FAISS

  • Stored embedding vectors in a FAISS index for fast nearest-neighbor lookup.
  • Embedded user queries using the same model to keep retrieval consistent.
  • Returned top-ranked document sections based on vector similarity scores.

Interactive Interface and Insights

  • Built a Streamlit interface for query input and readable retrieval output.
  • Used Plotly bar and pie charts to summarize extracted information.
  • Designed the workflow to make unstructured PDF knowledge easy to explore.
